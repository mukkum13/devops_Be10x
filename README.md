# devops_Be10x — PocketLedger

Personal finance web app built for the Be10x DevOps course.

## Files
| File | Purpose |
|---|---|
| `index.html`, `styles.css`, `app.js` | Main web app |
| `PocketLedger.html` | Single-file standalone build |
| `PRD_Personal_Finance_Webapp.md` | Product requirements document |
| `graphify-out/` | Knowledge-graph of the project (graph.html to browse) |

## Run locally
Open `index.html` (or `PocketLedger.html`) in a browser. No build step needed.
